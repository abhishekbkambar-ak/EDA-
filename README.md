# 🌸 Iris Dataset Analysis & Classification

## 📌 Overview
This project performs Exploratory Data Analysis (EDA) and classification on the Iris dataset using visualization techniques and a machine learning model.

---

## 🎯 Aim
To analyze the dataset and build a model to predict flower species.

---

## 🧠 Objectives
- Understand dataset structure  
- Visualize data using graphs  
- Preprocess data  
- Train and evaluate model  

---

## 📂 Dataset
- Iris Dataset  
- Features: Sepal Length, Sepal Width, Petal Length, Petal Width  
- Target: Species  

---

## ⚙️ Tools & Libraries
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  

---

## 📊 Visualizations
- Histogram  
- Line Plot  
- Bar Chart  
- Pie Chart  
- Heatmap (Correlation Matrix)  
- Pairplot  

---

## 🔄 Workflow
1. Load dataset  
2. Preprocess data  
3. Perform EDA  
4. Split dataset  
5. Scale features  
6. Train model (Random Forest)  
7. Evaluate performance  

---

## 🤖 Model
**Random Forest Classifier**

---

## 📈 Result
- Achieved high accuracy (~95%–100%)  
- Strong correlation found between petal features  

---

## ✅ Conclusion
EDA and ML techniques were successfully used to analyze and classify the Iris dataset with high accuracy.
